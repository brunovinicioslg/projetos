# 🏢 Sistema ACE/CDL — Lagoa Grande

## 📋 Descrição

Sistema ERP completo para a ACE/CDL de Lagoa Grande/MG. Gestão financeira, cadastro de associados, controle de caixa, emissão de boletos e relatórios gerenciais. Instalador automático para Windows Server.

## ✨ Funcionalidades

- ✅ Gestão de associados
- ✅ Controle financeiro e de caixa
- ✅ Emissão de boletos
- ✅ Relatórios gerenciais
- ✅ Autenticação JWT com perfis (admin/operador)
- ✅ Instalador automático (.bat / .ps1)
- ✅ Migrations versionadas (Prisma)

## 🛠️ Stack Tecnológico

| Tecnologia | Descrição |
|-----------|-----------|
| TypeScript | Linguagem principal |
| NestJS | Framework backend (Node.js) |
| PostgreSQL | Banco de dados |
| Prisma ORM | Mapeamento objeto-relacional |
| JWT + Roles | Autenticação e autorização |
| React | Frontend (separado) |

## ⚠️ Nota de Segurança

Este repositório contém **apenas código de demonstração**.
Variáveis de ambiente (`.env`), credenciais, tokens e dados sensíveis
foram **removidos** antes da publicação.
