# 📦 Leitor de Código de Barras

## 📋 Descrição

Sistema web para lista de compras com leitor de código de barras integrado. Autenticação com criptografia, perfis de usuário, gerenciamento de listas e recuperação de senha por e-mail.

## ✨ Funcionalidades

- ✅ Leitor de código de barras (câmera/USB)
- ✅ Lista de compras digital
- ✅ Autenticação com hash de senha
- ✅ Perfis de usuário (admin/padrão)
- ✅ Recuperação de senha por e-mail
- ✅ Deploy automatizado no Azure

## 🛠️ Stack Tecnológico

| Tecnologia | Descrição |
|-----------|-----------|
| C# | Linguagem principal |
| ASP.NET Core MVC | Framework web |
| Entity Framework Core | ORM e migrations |
| SQL Server | Banco de dados |
| Bootstrap | UI responsiva |
| Azure App Service | Hospedagem |

foram **removidos** antes da publicação.
