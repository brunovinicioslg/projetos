# 🗓️ Agendador de Serviços Técnicos

## 📋 Descrição

Sistema web para agendamento e gestão de serviços técnicos. Interface moderna com componentes shadcn/ui, backend gerenciado pelo Supabase (PostgreSQL + Auth + Storage).

## ✨ Funcionalidades

- ✅ Agendamento de atendimentos técnicos
- ✅ Gestão de clientes e histórico
- ✅ Dashboard com status de serviços
- ✅ Autenticação segura via Supabase
- ✅ PWA — instalável no celular
- ✅ Interface responsiva mobile-first

## 🛠️ Stack Tecnológico

| Tecnologia | Uso |
|-----------|-----|
| TypeScript | Linguagem principal |
| React + Vite | Frontend SPA |
| Supabase | Backend as a Service (PostgreSQL + Auth) |
| Firebase | Notificações push (FCM) |
| shadcn/ui + Tailwind CSS | UI e estilização |
| React PDF Renderer | Geração de documentos PDF |

## ⚠️ Nota de Segurança

Este repositório contém **apenas código de demonstração**.
Variáveis de ambiente (`.env`), credenciais, tokens e dados sensíveis
foram **removidos** antes da publicação.
