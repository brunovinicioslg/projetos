# 📸 ERP Fotógrafa

## 📋 Descrição

Sistema ERP completo para gestão de estúdio fotográfico. Módulos de clientes, produtos, serviços, financeiro e geração de PDFs. Arquitetura full-stack com API REST (Node.js/Express) e frontend em React.

## ✨ Funcionalidades

- ✅ CRUD de clientes com histórico de compras
- ✅ Catálogo de produtos e serviços com preços
- ✅ Controle financeiro
- ✅ Geração de orçamentos em PDF (PDFKit)
- ✅ Autenticação JWT com bcryptjs
- ✅ PWA instalável no celular
- ✅ Logs com Winston

## 🛠️ Stack Tecnológico

| Tecnologia | Uso |
|-----------|-----|
| Node.js + Express | API REST backend |
| React + Vite | Frontend SPA |
| PostgreSQL | Banco de dados relacional |
| Prisma ORM | Mapeamento objeto-relacional |
| JWT + bcryptjs | Autenticação segura |
| PDFKit | Geração de orçamentos em PDF |

## ⚠️ Nota de Segurança

Este repositório contém **apenas código de demonstração**.
Variáveis de ambiente (`.env`), credenciais, tokens e dados sensíveis
foram **removidos** antes da publicação.
