# 🎲 Sistema de Sorteio

## 📋 Descrição

Aplicação web para realização de sorteios digitais. Sistema com autenticação de usuários por perfil (admin/padrão), cadastro e sorteio de participantes por código único, com histórico de sorteios realizados.

## ✨ Funcionalidades

- ✅ Cadastro de participantes com código único
- ✅ Realização de sorteios com registro
- ✅ Autenticação por perfis (admin/padrão)
- ✅ Histórico de sorteios
- ✅ Deploy automatizado no Azure via GitHub Actions

## 🛠️ Stack Tecnológico

| Tecnologia | Descrição |
|-----------|-----------|
| C# | Linguagem principal |
| ASP.NET Core MVC | Framework web |
| Entity Framework Core | ORM e migrations |
| SQL Server | Banco de dados |
| Bootstrap | UI responsiva |
| Azure App Service | Hospedagem |

foram **removidos** antes da publicação.
