# 🎮 TerraQuest Battle Run

## 📋 Descrição

Jogo fitness baseado em geolocalização. O jogador conquista territórios reais no mapa se deslocando fisicamente. Com coach de IA (Google Gemini) que dá dicas motivacionais personalizadas baseadas no desempenho.

## ✨ Funcionalidades

- ✅ Mapa interativo (Leaflet) com territórios reais
- ✅ Conquista de territórios por GPS/deslocamento
- ✅ Coach de IA (Google Gemini API)
- ✅ Estatísticas de atividade física
- ✅ Interface gamificada com níveis
- ✅ Sem backend — funciona 100% no cliente

## 🛠️ Stack Tecnológico

| Tecnologia | Descrição |
|-----------|-----------|
| TypeScript | Linguagem principal |
| React + Vite | Frontend SPA |
| Leaflet + react-leaflet | Mapa interativo |
| Google Gemini AI | Coach de IA para motivação |
| Geolocation API | GPS do dispositivo |
