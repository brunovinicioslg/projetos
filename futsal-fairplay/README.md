# ⚽ Futsal FairPlay

## 🌐 Em Produção

🔗 **[https://bvcinformatica.com/appfutsal](https://bvcinformatica.com/appfutsal)**

## 📋 Descrição

Aplicativo web para gestão de campeonatos e times de futsal. Tabelas de classificação em tempo real, resultados, cadastro de atletas e notificações push via Firebase. Disponível em produção.

## ✨ Funcionalidades

- ✅ Gestão de campeonatos e fases
- ✅ Tabelas e classificação em tempo real
- ✅ Registro de resultados e gols
- ✅ Cadastro de times e atletas
- ✅ Notificações push (Firebase FCM)
- ✅ PWA instalável
- ✅ Testes automatizados (Vitest)

## 🛠️ Stack Tecnológico

| Tecnologia | Descrição |
|-----------|-----------|
| TypeScript | Linguagem principal |
| React + Vite | Frontend SPA |
| Supabase | Backend as a Service (PostgreSQL + Auth) |
| Firebase | Notificações push (FCM) |
| shadcn/ui + Tailwind CSS | UI e estilização |
| Vitest | Testes unitários |
