# 🔄 Atualizador Automático — SIAP

## 📋 Descrição

Sistema de atualização automática para o software SIAP. Automatiza o processo de download e instalação de atualizações via navegador headless (Puppeteer). Empacotado como executável Windows (.exe) via pkg.

## ✨ Funcionalidades

- ✅ Login automático no sistema SIAP
- ✅ Detecção de novas versões disponíveis
- ✅ Download e instalação automatizados
- ✅ Scheduler de execução programada
- ✅ Logs detalhados de cada etapa
- ✅ Empacotamento como .exe (sem Node.js necessário)

## 🛠️ Stack Tecnológico

| Tecnologia | Descrição |
|-----------|-----------|
| Node.js | Runtime JavaScript |
| Puppeteer | Automação de navegador headless |
| pkg | Empacotamento como executável .exe |
| Winston | Sistema de logs |

## ⚠️ Nota de Segurança

Este repositório contém **apenas código de demonstração**.
Variáveis de ambiente (`.env`), credenciais, tokens e dados sensíveis
foram **removidos** antes da publicação.
